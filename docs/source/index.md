# Sledra 中文文档

Sledra 保存工作流的原始运行事实，提供独立 Go 记录器、Bash owner 钩子和可搬运的 Linux 试用包。当前已完成 M1/M1.5 本地验收，离线分析和真实采集确认留待 M2。

首次使用请阅读[快速开始](quickstart.md)或[安装指南](installation.md)。共享/HPC 部署与性能、发行资格需要单独验证，详见[支持矩阵](support.md)。
